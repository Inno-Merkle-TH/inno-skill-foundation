# Learning evidence

- ผู้เรียน / บท / วันที่:
- Environment และ versions (ไม่มี secrets):
- Requirement และ expected behavior:
- Input/fixture (synthetic เท่านั้น):
- ขั้นตอนและ command พร้อม directory:
- Observed result / assertion:
- Evidence paths / PR URL ที่ทีมอนุญาต:
- Negative test และ defect ที่จับได้:
- Risk / impact ต่อธุรกิจและ tracking:
- Cleanup / rollback ที่ทำ:
- สิ่งที่ยังไม่ได้ verify:
- AI assistance และส่วนที่ผู้เรียนตรวจเอง:
- สถานะ: ทำแล้วและตรวจแล้ว / ต้องลองใหม่ / ยังไม่ทำ / ไม่ใช้ในขอบเขตนี้:
- Checklist ที่ยังไม่ครบ / สาเหตุ / สิ่งที่จะลองต่อ:
- คำอธิบายด้วยตัวเองและ fixture ที่ลองเปลี่ยน:
- Feedback (ถ้ามี) / next action / ผู้ช่วยเมื่อจำเป็น:

## ตรวจบันทึกก่อนแชร์

- [ ] Expected เขียนก่อนทดลอง และ actual มาจากผลที่เห็นจริง
- [ ] มี directory/command/commit และผลที่ทำซ้ำได้
- [ ] แยก local/mock/design/live ไม่ใช้ผลหนึ่งแทนอีกผล
- [ ] มี failure case, วิธีคืนระบบ และสิ่งที่ยังไม่ verify
- [ ] ไม่มี secret/PII/raw HAR; link หลักฐานเปิดได้ตามสิทธิ์

ใช้หนึ่งชุดต่อบท ไม่คิดคะแนน; checklist ที่ยังไม่ครบคือรายการทำต่อ ไม่ใช่ให้ติ๊กเพื่อส่งงาน
